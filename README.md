# German Restaurant VAT Cut (19% → 7%): A Simulated Dining-Behavior Study

An independent portfolio project. It asks: **how would a permanent cut in VAT on restaurant food change diner behavior, and which diners would respond most?** It answers with a difference-in-differences (DiD) analysis and an honest causal forest on **simulated** data with known effects, so the estimators can be checked against the truth.

> **Not real data ** Every record is generated by code (`seed = 42`) and is modeled loosely on the structure of aggregated card-transaction data. Nothing here measures the actual effect of Germany's policy.

## The policy
Since January 1, 2026, Germany permanently taxes restaurant and catering **food** at 7% (previously 19%). **Beverages stay at 19%.** The study treats Germany (Region A) as treated and compares it with a neighboring metro, with the cut taking effect on January 1, 2026.

## What's in this repo
- `app.py`: Streamlit app with three views (`Data visualizations`, `Difference in Difference`, `Causal Forest`) and an assumptions panel
- `vat_executive_summary.md`: one-page research brief
- `requirements.txt`: tested package versions

## Method
1. **Simulated data:** four regions, 11,200 diner records, January 2024 to October 2026 (a repeated cross-section, not a panel). The outcome is an expected "dining-out pullback rate." The true effect of the cut varies by diner profile and is stored in the data so estimates can be checked.
2. **Difference-in-differences:** Germany vs. each candidate comparison region, with a pre-trend test. Only the Benelux border metro passes; Southern Europe and the Nordics trend differently, which shows why the choice of control matters.
3. **Honest causal forest:** EconML's `CausalForestDML`, cross-fitted in two folds. Trees use separate subsamples to choose splits and to estimate leaf effects ("honesty"). Outcomes are baseline-adjusted by each region's pre-2026 mean so the forest's average is comparable to the DiD estimate.

## Results from the simulation
| Estimate | Result |
|---|---|
| DiD, Germany vs. Benelux border metro | about -2.9 pp (p < 0.001); pre-trend test p ≈ 0.52 |
| DiD vs. Southern Europe / Nordics | pre-trend tests fail (p < 0.001), so those comparisons are not credible |
| Causal forest, cross-shopping casual diners | about -3.7 pp (95% CI -4.0 to -3.4); truth -3.8 |
| Causal forest, occasional neighborhood diners | about -3.6 pp (95% CI -3.9 to -3.3); truth -3.3 |
| Causal forest, weekly regulars | about -1.5 pp (95% CI -1.8 to -1.3); truth -1.3 |

The forest recovers the segment pattern to within about 0.25 pp. The intervals are approximate, and the weekly-regulars truth sits just outside its interval.

## Assumptions and limitations
- **Parallel trends are built into the simulation**, so passing the pre-trend test is expected. Real data would need to earn it.
- **Pass-through is assumed.** The simulation assumes the tax saving reaches diners. Real-world evidence suggests restaurants have passed on little of the cut in menu prices, which would shrink the effect.
- **Possible spillovers:** diners crossing the border to eat in Germany could contaminate a border-metro control.
- **Treatment is assigned by region, not at random.** The forest relies on parallel trends plus the assumption that diner profiles capture the relevant differences.
- **Simplified inference:** standard errors treat each diner as independent; real analyses would cluster, and two regions give very few clusters.
